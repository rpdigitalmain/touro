# Security Policy

Use GitHub's private form to report a vulnerability in Touro. [Report a vulnerability](https://github.com/rpdigitalmain/touro/security/advisories/new).

Include the affected Touro version, your operating system, whether you used the npm CLI or the standalone executable, and the steps and impact you observed. Remove secrets and personal data from any attachments.

If the private form is unavailable, open an issue asking for a private contact and keep vulnerability details out of the public thread. [Request a private contact](https://github.com/rpdigitalmain/touro/issues/new).
